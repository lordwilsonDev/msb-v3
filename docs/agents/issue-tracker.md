# Issue Tracker

This repo uses **GitHub Issues** as its issue tracker.

## Conventions

- Create issues via `gh issue create` or the GitHub web UI.
- Label issues with the triage labels from `triage-labels.md`.
- The `to-tickets`, `triage`, and `to-spec` skills read from and write to GitHub Issues.
- PRs are **not** used as a request surface by default. If you want external PRs in the triage queue, flip this flag manually.
