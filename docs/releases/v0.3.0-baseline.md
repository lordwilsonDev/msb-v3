## What changed since rc2 (verified in this baseline)

1. **Key-rotation / recovery ceremony** — `KeyRegistry`
   (`chain_key_registry.json`): cross-signed successor endorsements
   (`--rotate`), offline recovery key (`--register-recovery` / `--recover`),
   signed revocations (`--revoke`). Historical notary entries stay
   verifiable across rotation. Docs: `docs/operations/yubikey-piv-anchor.md`,
   `docs/operations/secure-enclave-anchor.md`.
2. **YubiKey PIV backend wired** — real PKCS#11 signing (python-pkcs11 +
   libykcs11), on-device keygen, CKA_ID slot selection, hermetic tests.
3. **Anchor key out of plaintext** — seed moved to the macOS login keychain;
   `.env` is `0600`.
4. **Type gate** — targeted mypy override for `asn1crypto`; bare `mypy src`
   is green.
5. **Convergence pass** — multimodal interfaces relabeled `parked`
   (`blocked_on: mac-mini-storage`); the NotImplementedError and "Phase 2"
   markers audited (abstract contracts + provenance comments, KEEP);
   mid-run kill-switch halt test added.

## Known limitations (honest)

- Hardware anchor enrollment (Secure Enclave / YubiKey) still pending an
  Apple ID or a purchased key — the keychain interim is live and verified;
  the hardware backends fail closed until enrolled.
- Multimodal is parked (not shipped) behind `MSB_MULTIMODAL_ENABLED`.
- M6 30-day operating trial is in progress (first weekly review
  2026-08-22); M7 independent-user validation not yet scheduled.
- A full RFC 8785 (JCS) canonicalization migration is deferred to a
  versioned migration (record hashes would change); non-finite floats are
  rejected at append so the chain is canonical for JSON-native types.

## Known unverified claims

- Live frontier-provider path (`tests/live/test_frontier_smoke.py`) — opt-in,
  unverified without a configured provider.
- Docker build is reproducible from the locks but not exercised in this
  baseline (macOS host).
