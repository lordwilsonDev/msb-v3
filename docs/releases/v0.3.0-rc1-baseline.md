## Known limitations (carried forward, v0.3.0-rc1)

1. No formal DB schema versioning / migrations (UNKNOWN schema versions in
   `data/*.db`). This is a Phase 1/3 debt item.
2. Factory LLM reviewer (qwen3:8b/0.5b) missed a seeded doc contradiction
   live; the deterministic coherence scan (`scan_doc_contradictions`) is the
   catch. Hermetic M4 suite proves the deterministic MoIE reviewer catches
   seeded defects. Residual: model-strength limit, recorded not hidden.
3. CLI agent provider is documented "best-effort isolation, not a sandbox" —
   strong sandbox (Phase L9) not yet built.
4. Tenant chat LLM routing is not tenant-scoped (RAG is) — L10 partial.
5. `data/` runtime state partially git-tracked (SMI-017 #10 partial).
6. Deleted-file diffs are not emitted by factory `compute_changes` (new-file
   diffs fixed 2026-08-17; deletion case out of scope).

## Expansion freeze

Active from this baseline per the convergence-to-12 program: **no new
subsystem or modality enters the v3 shipping surface without a written
exception tied to a failure found in the canonical live path or a measured
user-value gap.** New ideas go to `docs/blueprints/convergence-to-12/v4-parking-lot.md`.
